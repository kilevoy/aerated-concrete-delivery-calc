# Газобетон на объекте

Калькулятор цены автоклавного газобетона с доставкой до места стройки: ИНСИ Блок против Теплита, Поревита и Пораблока в УрФО.

**Репозиторий приватный.** В нём внутренний прайс и данные конкурентной разведки — не делать публичным и не включать GitHub Pages без обезличивания.

## Как открыть

Откройте `index.html` в браузере. Сервер и сборка не нужны, интернет нужен только для шрифтов Google Fonts.

## Что считает

- Цена на объекте = цена завода + доставка / объём.
- Доставка = число фур × км × тариф. Фур = объём / вместимость фуры, с округлением вверх.
- Сравнение с ближайшим конкурентом: запас для повышения цены или нужная скидка.
- Залог за поддоны ИНСИ (250 ₽ за поддон на 1,5 м³) показан отдельно, в цену не входит.

Вводятся: населённый пункт или координаты, объём, тариф ₽/км, вместимость фуры, тип покупателя ИНСИ (юрлицо или физлицо), цены заводов.

## Откуда расстояния

Только реальные маршруты по дорогам, по прямой калькулятор не считает.

| Случай | Источник |
|---|---|
| Пункт из справочника (118 шт.: Челябинская обл. и соседние регионы) | Готовая матрица OSRM / OpenStreetMap, расчёт 18.10.2026 (`data/roads.json`, константа `ROADS` в `index.html`) |
| Любой другой адрес или координаты | Кнопка «Построить маршрут»: адрес ищется через Nominatim (запасной — Photon), маршрут строится через OSRM онлайн |
| Ручной ввод км в таблице | Значение пользователя, приоритет над остальными |

Онлайн-маршруты работают, когда `index.html` открыт в обычном браузере. В карточке артефакта Claude внешние запросы закрыты — там работают справочник и ручной ввод.

Координаты заводов уточнены по адресам: ИНСИ Блок — п. Зауральский, ул. Труда 1а; Теплит Березовский — ул. Чапаева 39; Пораблок — пр. Маршала Голикова 29. Для Рефтинского, Сысерти и Ялуторовска — центр населённого пункта.

OSRM не учитывает ограничения для грузовиков: весовые знаки, мосты, зимники. Для крупной сделки сверяйте расстояние с перевозчиком.

Пересчитать матрицу: `python3 scripts/build_roads.py` — обновит `data/roads.json` и `ROADS` в `index.html`.

## Ограничения

- Заводы не ставят дату на прайс, актуальность цен не подтверждена.
- Дилерские скидки конкурентов не учтены: у дилера в Челябинске Теплит стоит 4 300 ₽/м³ против 5 800 на заводе.
- Введённые данные хранятся только в браузере пользователя (localStorage).
